## 🇺🇸 English Version

I am a **Cloud, SRE & DevOps Engineer** with a solid background in critical infrastructure, high-availability environments, Linux kernel tuning, and network engineering. Holding a B.S. in Information Systems and a Postgraduate specialization in **Cybersecurity**, I bridge the gap between resilient cloud architecture, deep observability, and **AI-driven automation (AIOps & RAG Agents)** to reduce MTTR and scale operations.

- 🔭 **Focus:** Architecting resilient Multi-Cloud infrastructures (AWS, OCI, GCP, Azure), Kubernetes clusters, and end-to-end Observability pipelines.
- 🧠 **AI in Production:** Building autonomous SRE RAG Agents, vector search engines (`pgvector` / FAISS), and LLM workflows to accelerate incident root-cause analysis (RCA).
- 🛡️ **Security & Reliability:** Implementing Pod Security Standards, Chaos Engineering, Infrastructure as Code (Terraform/Ansible), and FinOps best practices.
- ⚡ **Tech Creator:** Sharing practical insights on Cloud, Containers, Linux, and SRE on [Instagram (@carlosmagno_cloudengineer)](https://www.instagram.com/carlosmagno_cloudengineer/) and [LinkedIn](https://www.linkedin.com/in/carlosmagnogcs/).
